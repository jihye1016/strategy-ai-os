**버전:** v1.0
**기준일:** 2026-06-29
**목적:** 수집된 데이터를 C-level 의사결정 가능한 전략 분석으로 변환하는 절차와 로직 정의

## 원칙: 분석의 3단계

```
1단계: FACT      → 검증된 데이터 수집 (출처 필수)
2단계: ANALYSIS  → 프레임워크 적용 → 패턴·구조 도출
3단계: INSIGHT   → 사업적 의미 + CEO 의사결정 항목 생성
```

각 단계는 반드시 순서대로 진행한다.
FACT 없이 ANALYSIS 불가. ANALYSIS 없이 INSIGHT 불가.

## Module 1. 시장 규모 분석 (TAM / SAM / SOM)

### 정의

| 개념 | 정의 | 산출 방법 |
|---|---|---|
| TAM (Total Addressable Market) | 해당 산업 전체 시장 | 공식 시장조사 수치 인용 (Tier1·2 출처) |
| SAM (Serviceable Addressable Market) | 자사가 실제 공략 가능한 세그먼트 | TAM × 타깃 고객군 비율 |
| SOM (Serviceable Obtainable Market) | 현실적으로 점유 가능한 시장 | SAM × 현재 역량 기반 달성 가능 점유율 |

### 산출 로직

```
Step 1. TAM 확정
  - 공식 출처 시장 규모 수치 확보 (Tier1·2 필수)
  - 복수 출처 존재 시 보수적 수치 채택 + 출처 병기

Step 2. SAM 산출
  - TAM에서 자사 서비스 대상 세그먼트 필터링
  - 필터 기준: 지역(국내/글로벌) / 고객군(B2B/B2C) / 기능 범위
  - 수식: SAM = TAM × (타깃 세그먼트 비율)

Step 3. SOM 산출
  - 현재 자사 역량 (인력, 자본, 파트너십, 기술) 평가
  - 경쟁 강도 반영 (경쟁사 점유율 차감)
  - 보수적(Conservative) / 기준(Base) / 낙관적(Optimistic) 3개 시나리오 제시
  - 수식: SOM = SAM × 달성 가능 점유율 (시나리오별)

Step 4. CEO Decision Point 연결
  - SOM 달성을 위한 전제 조건 명시
  - 각 시나리오별 필요 자원 (인력/예산/기간) 산출
```

### 출력 형식

```markdown
## 시장 규모 (TAM/SAM/SOM)

| 구분 | 규모 | 기준 | 출처 |
|---|---|---|---|
| TAM | [수치] | [정의] | [URL] |
| SAM | [수치] | [필터 기준] | 산출 |
| SOM (보수) | [수치] | [가정] | 산출 |
| SOM (기준) | [수치] | [가정] | 산출 |
| SOM (낙관) | [수치] | [가정] | 산출 |

→ CEO Decision Point: SOM [기준] 달성을 위해 [자원]이 필요하며, [기한]까지 [결정]이 필요하다.
```

## Module 2. 경쟁사 포지셔닝 분석

### 분석 항목 (경쟁사별 동일 템플릿 적용)

```
1. 기본 정보: 회사명 / 설립연도 / 모회사 / 매출 (공시 기준)
2. 핵심 서비스: 서비스명 / 출시일 / 타깃 고객 / BM
3. AI 기술 역량: 사용 기술 / 데이터 자산 / 특허
4. 시장 포지션: 점유율 / 고객 수 / 파트너십
5. 전략 방향: 최근 6개월 주요 행보
6. 강점 / 약점 (공식 확인 가능한 항목만)
7. 위협 수준: 상/중/하 + 근거
8. 다나아데이터 대비 차별점
9. 벤치마킹 포인트
```

### 포지셔닝 매트릭스 산출 로직

```
X축: AI 기술 역량 (데이터·모델·특허 기반 평가)
Y축: 시장 침투도 (고객 수·파트너십·채널 기반 평가)

각 항목 1~5점 채점:
  AI 기술 역량 = (LLM/자체모델 보유 여부 × 2) + (데이터 자산) + (특허 수)
  시장 침투도  = (고객사 수) + (채널 수) + (파트너십 수)

→ 매트릭스에 경쟁사 위치 표시
→ 자사(다나아데이터) 위치 표시
→ 공백 영역 = 기회 영역
```

### 위협 타임라인 산출

```
각 경쟁사의 자사 영역 진입 예상 시점을 아래 기준으로 판단:
  - 즉시 위협 (0~6개월): 이미 동일 기능 출시
  - 단기 위협 (6~12개월): 개발 중 또는 채용 공고 확인
  - 중기 위협 (12~24개월): 인접 영역 진출 후 확장 예상
  - 장기 위협 (24개월+): 방향성만 존재
```

## Module 3. 비즈니스 모델 (BM) 분석

### Business Model Canvas 9개 블록

```
1. 고객 세그먼트 (Customer Segments)
   - B2B: 기업 규모별 / 산업별 / 지역별 분류
   - B2C: 연령 / 건강 상태 / 검진 이력 기반 분류

2. 가치 제안 (Value Proposition)
   - 각 세그먼트별 핵심 문제 정의
   - 자사 서비스가 해결하는 방식 명시
   - 경쟁사 대비 차별점 1~2가지

3. 채널 (Channels)
   - 현재 채널: 직접영업 / 검진기관 제휴 / 앱 / 웹
   - 확장 가능 채널: 보험사 / 약국 / 제약사 제휴

4. 고객 관계 (Customer Relationships)
   - B2B: 계약 기반 / 전담 CS / 정기 리뷰
   - B2C: 앱 푸시 / AI 코칭 / 커뮤니티

5. 수익 흐름 (Revenue Streams)
   - 현재 수익 모델 (공식 확인 가능 항목만)
   - 잠재 수익 모델 (Insight로 표시)

6. 핵심 자원 (Key Resources)
   - 데이터: 임상 데이터 / 수검 데이터 규모
   - 기술: LLM / AI 모델 / 특허
   - 파트너십: 검진기관 / 모회사 채널

7. 핵심 활동 (Key Activities)
   - AI 모델 개발·고도화
   - 검진기관 제휴 확장
   - 기업 고객 영업

8. 핵심 파트너십 (Key Partnerships)
   - 현재 파트너 (공식 확인)
   - 필요 파트너 (전략적 권고)

9. 비용 구조 (Cost Structure)
   - 주요 비용 항목 (공개 정보 기반)
```

### 분석 로직


## Module 5. SWOT 분석

### 작성 규칙

```
각 항목은 반드시 출처 또는 근거 명시.
추상적 항목 금지: "기술력 우위" (X) → "HyperCLOVA X 기반 LLM 적용, KMI 40만 임상 데이터 학습" (O)

Strength:    자사가 현재 보유한 검증된 강점
Weakness:    자사가 현재 가진 확인된 약점
Opportunity: 외부 환경에서 확인된 기회 요인 (데이터 기반)
Threat:      외부 환경에서 확인된 위협 요인 (데이터 기반)
```

### SO/ST/WO/WT 전략 도출

```
SO 전략: 강점으로 기회를 극대화 → 공격적 성장 전략
ST 전략: 강점으로 위협을 최소화 → 경쟁 방어 전략
WO 전략: 약점을 보완해 기회를 포착 → 역량 강화 전략
WT 전략: 약점과 위협을 동시 관리 → 리스크 관리 전략

→ 각 전략은 구체적 액션 아이템으로 연결
```

## Module 6. Porter 5 Forces 분석

### 5개 Force 평가 기준

```
Force 1. 신규 진입 위협 (Threat of New Entrants)
  평가 항목: 규제 장벽 / 데이터 장벽 / 자본 요구 / 기술 장벽
  점수: 1(낮음)~5(높음)

Force 2. 공급자 교섭력 (Bargaining Power of Suppliers)
  평가 항목: 데이터 공급자 집중도 / LLM 의존도 / 검진기관 의존도
  점수: 1(낮음)~5(높음)

Force 3. 구매자 교섭력 (Bargaining Power of Buyers)
  평가 항목: 고객 전환 비용 / 대안 서비스 존재 여부 / 고객 집중도
  점수: 1(낮음)~5(높음)

Force 4. 대체재 위협 (Threat of Substitutes)
  평가 항목: 기존 검진 상담 서비스 / 의사 직접 상담 / 타 AI 서비스
  점수: 1(낮음)~5(높음)

Force 5. 경쟁 강도 (Industry Rivalry)
  평가 항목: 경쟁사 수 / 성장 속도 / 차별화 정도 / 철수 장벽
  점수: 1(낮음)~5(높음)
```

### 출력: 산업 매력도 평가

```
각 Force 점수 합산 → 산업 매력도 = 25 - 합산점수 (높을수록 매력적)
→ 자사에 유리한 Force / 불리한 Force 식별
→ 전략적 대응 방안 도출
```

## Module 7. Value Chain 분석

### 분석 구조

```
주요 활동 (Primary Activities):
  1. 데이터 수집: 검진 데이터 확보 경로 및 품질
  2. AI 개발: 모델 개발·학습·검증 프로세스
  3. 서비스 운영: 플랫폼 운영 및 CS
  4. 영업·마케팅: B2B/B2C 채널 및 고객 획득
  5. 사후 서비스: 데이터 업데이트 및 정확도 관리

지원 활동 (Support Activities):
  1. 인프라: 클라우드 / 보안 / 컴플라이언스
  2. 인사: AI 엔지니어 / 의료 전문가 확보
  3. 기술 개발: 특허 / R&D 투자
  4. 조달: 검진 데이터 / LLM 파트너십

→ 각 활동별 자사 vs 경쟁사 역량 비교
→ 차별화 포인트 및 원가 우위 포인트 식별
```

## Module 8. Opportunity Map

### 기회 영역 도출 로직

```
Step 1. 고객 여정 맵 작성
  검진 전 → 검진 예약 → 검진 당일 → 결과 수령 → 결과 해석 → 관리·치료

Step 2. 각 단계별 현재 서비스 현황 매핑
  - 자사 서비스 커버 여부
  - 경쟁사 서비스 커버 여부
  - 미충족 수요(Unmet Need) 식별

Step 3. 기회 영역 평가 (2×2 매트릭스)
  X축: 시장 규모 (대/소)
  Y축: 진입 난이도 (낮음/높음)
  → 우선 공략 영역: 시장 크고 진입 쉬운 영역
  → 중기 공략 영역: 시장 크고 진입 어려운 영역

Step 4. 기회별 추진 시나리오
  - 자체 개발 / 파트너십 / M&A 3개 옵션 제시
  - 각 옵션별 소요 자원 및 기간 산출
```

## Module 10. KPI 프레임워크

### KPI 계층 구조

```
Level 1. 경영 KPI (CEO 보고)
  - 매출 / ARR / 영업이익률 / 시장점유율

Level 2. 사업 KPI (사업부 보고)
  - B2B: 계약 기업 수 / 계약 금액 / 이탈률
  - B2C: MAU / DAU / 유료전환율 / LTV

Level 3. 운영 KPI (팀 보고)
  - AI 정확도 / 응답 속도 / CS 해결률 / 데이터 품질
```

### KPI 목표 설정 로직

```
Step 1. 기준점(Baseline) 확인: 현재 수치 (공식 데이터 또는 내부 데이터)
Step 2. 벤치마크 설정: 경쟁사 또는 유사 서비스 수치 참조
Step 3. 목표 설정: 기준점 × 성장률 (근거 명시)
Step 4. 마일스톤: 분기별 중간 목표 설정
```

## Module 11. CEO Decision Point 생성 로직

### 자동 생성 조건

분석 완료 후 아래 조건에 해당하는 항목을 CEO Decision Point로 자동 분류:

```
조건 1. 기한이 있는 결정 사항
  → 경쟁사 진입 예상 시점 6개월 이내
  → 정책 시행 또는 시장 변화 시점 이내

조건 2. 자원 배분이 필요한 결정 사항
  → 인력 채용 / 예산 투자 / 파트너십 체결

조건 3. 방향성을 결정하는 전략적 선택
  → A/B 두 개 이상의 선택지가 존재
  → 선택에 따라 1년 이상의 방향이 달라지는 사안

조건 4. 리스크 수용 여부를 결정해야 하는 사항
  → 규제 리스크 / 경쟁 리스크 / 기술 리스크
```

### Decision Point 품질 기준

- 1개 Decision Point = 1개 명확한 질문
- 옵션은 2~3개 (과도한 옵션 금지)
- 각 옵션에 기대 효과 + 리스크 + 필요 자원 명시
- 권고안은 반드시 1개로 압축 (근거 포함)
- 결정 기한 명시 (날짜 또는 분기)
