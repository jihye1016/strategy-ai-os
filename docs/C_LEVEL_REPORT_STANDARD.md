# CEO/임원 보고서 품질 기준

**버전:** v1.0
**기준일:** 2026-06-29
**적용 범위:** ESIP에서 생성되는 모든 전략 보고서

---

## 1. 보고서의 존재 목적

이 보고서는 CEO와 임원이 읽고 **즉시 의사결정**을 내릴 수 있어야 한다.
분석을 위한 분석, 정보를 위한 정보는 이 보고서의 목적이 아니다.

모든 페이지는 다음 질문에 답해야 한다:
> "이 내용을 읽은 CEO가 무엇을 결정해야 하는가?"

---

## 2. 보고서 구조 (필수)

### 필수 섹션 순서

```
Section 1.  Executive Summary          (1페이지 이내)
Section 2.  CEO Decision Point         (명시적 의사결정 항목)
Section 3.  시장 기회 (TAM/SAM/SOM)
Section 4.  경쟁사 현황 및 위협 평가
Section 5.  Fact Base (근거 데이터)
Section 6.  전략 분석 (SWOT / Porter / Value Chain)
Section 7.  전략 제언 (우선순위 + KPI + 기한)
Section 8.  3개년 Roadmap
Section 9.  리스크 평가
Section 10. QA Score
Section 11. References
```

### Section 1 — Executive Summary 작성 규칙

- **3줄 요약** 필수: 결론 → 근거 → 액션
- 수치 반드시 포함 (시장 규모, 경쟁사 현황, KPI)
- 보고서 전체를 읽지 않아도 핵심을 파악할 수 있어야 함
- 길이: 300자 이내

### Section 2 — CEO Decision Point 작성 규칙

반드시 다음 형식으로 작성:

```
Decision #N
질문: [CEO가 결정해야 할 사항을 1문장 의문문으로]
옵션 A: [선택지 A]  → 기대 효과 / 리스크
옵션 B: [선택지 B]  → 기대 효과 / 리스크
권고:   [A 또는 B]  → 근거 2~3가지
기한:   [언제까지 결정해야 하는가]
```

CEO Decision Point는 반드시 **2개 이상, 5개 이하**로 작성한다.
추상적 제언("시장 확대가 필요하다")은 Decision Point가 아니다.
구체적 선택("비즈36.5 고객사를 Q3까지 10개 추가할 것인가 / 20개 추가할 것인가")이 Decision Point다.

## 3. 문장 작성 기준

### 구조
```
결론 먼저 → 근거 2~3개 → 사업적 의미 → 실행 제안
```

### 예시 (올바른 문장)
> 다나아데이터는 건강검진 결과 해석 AI 시장에서 선점 우위를 보유하고 있다.
> 근거: ① 에스크미가 2024년 9월 상용 서비스를 개시한 유일한 플랫폼이며,
> ② 주요 경쟁사(카카오헬스케어, GC케어) 모두 동 기능을 미보유하고,
> ③ KMI 검진 데이터 학습을 통한 진입장벽이 형성되어 있다.
> 이 우위는 12~18개월 내 경쟁사 진입이 예상되므로, 2026년 하반기 B2B 채널 고착화가 임박한 과제다.

### 예시 (금지 문장)
> "AI 헬스케어 시장은 매우 빠르게 성장하고 있으며, 다나아데이터도 이에 발맞춰 성장할 것으로 기대된다."
- 수치 없음 / 출처 없음 / 액션 없음 → 삭제

## 4. 반드시 포함할 의사결정 항목

| 항목 | 내용 | 형식 |
|---|---|---|
| 시장 규모 | TAM / SAM / SOM 수치 | 숫자 + 출처 |
| 경쟁사 위협도 | 상/중/하 + 근거 | 표 |
| 전략 우선순위 | 1~3순위 | 번호 목록 |
| KPI | 측정 가능한 수치 목표 | 수치 + 기한 |
| 투자/자원 요구 | 인력, 예산, 파트너십 | 구체 항목 |
| 리스크 | 발생 가능성 + 영향도 | 매트릭스 |
| 결정 기한 | 언제까지 결정해야 하는가 | 날짜 |

## 5. 레퍼런스 기준

### Tier 분류

| Tier | 출처 유형 | 예시 |
|---|---|---|
| Tier 1 | 정부기관, 공공기관, 기업 공시, 공식 홈페이지, 논문, 특허 | 국민건강보험공단, 보건복지부, 기업 공식 발표 |
| Tier 2 | 국제기관, 글로벌 컨설팅사 | WHO, OECD, McKinsey, KPMG, PwC |
| Tier 3 | 전문 언론, 신뢰도 높은 경제지 | 조선비즈, 헬스경향, 팜뉴스 |
| 사용 불가 | 블로그, 광고성 콘텐츠, 출처 불명 통계 | 네이버 블로그, 작성자 불명 기사 |

### 수치 사용 규칙

- 모든 수치에 출처 URL 필수
- 예측·추정 수치는 반드시 "(전망)" 또는 "(추정)" 명시
- 두 출처의 수치가 상충하면 양쪽 모두 기재 후 차이 설명
- 출처 확인 불가 수치는 보고서에서 제외 (추정 금지)

## 6. 금지사항

아래 항목이 보고서에 포함되면 QA에서 즉시 반려한다.

| 금지 항목 | 예시 |
|---|---|
| 출처 없는 수치 | "시장 규모는 약 10조원으로 추정된다" (출처 없음) |
| 가설을 사실처럼 서술 | "다나아데이터는 시장을 선도할 것이다" |
| 추상적 권고 | "지속적인 혁신이 필요하다" |
| KPI 없는 전략 제언 | "B2B 확대를 추진해야 한다" (수치/기한 없음) |
| Fact와 Opinion 혼재 | 수치 문장에 의견 삽입 |
| 중복 문장 | 같은 내용 반복 기술 |
| 임원 보고에 부적합한 문체 | "~것 같습니다", "~로 보여집니다" |
| 결론 없는 분석 | 데이터 나열 후 시사점 없음 |
